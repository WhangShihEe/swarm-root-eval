# 05: Bespoke live + review messageboard UI (stretch)

**What to build:** A bespoke, human-friendly UI to explore the forum — both **live** (watch the board and
DMs update as a swarm runs) and as a **review** of a finished run. Deliberately the final piece: large
scope, high polish, not on the critical path. The leaner interim (run the swarm, then `report.py`, and
read raw `inspect view` logs when needed) already covers day-to-day needs; this ticket is the flashy
upgrade.

**Blocked by:** 01.

**Status:** backlog (not ready-for-agent — stretch, sequenced last)

- [ ] A UI renders the forum (board messages + DMs + agent statuses) in a human-friendly view.
- [ ] The UI can follow a running swarm live and can open a finished run for review.
- [ ] Scope, framework, and hosting are decided in a dedicated design pass before implementation starts.
